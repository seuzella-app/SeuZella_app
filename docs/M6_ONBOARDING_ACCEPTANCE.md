# M6 — Onboarding Acceptance

## Target
P90 onboarding time <= 30 minutes for a standard property configuration.

## Required flow
1. Owner account activated.
2. Property created.
3. Rooms configured.
4. Calendar/channel integrations configured when applicable.
5. Payment provider selected and verified.
6. WhatsApp verified when enabled.
7. Fiscal profile configured when enabled.
8. Room-to-lock mappings validated.
9. First reservation/payment path tested.
10. Owner receives operational handoff and support channel.

## Evidence
Record timestamps for each step and the final onboarding duration.
