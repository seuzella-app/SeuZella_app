# Pilot Onboarding Runbook — Seu Zélla

## Phases
1. Property and owner identity verified.
2. Tenant created and admin access validated.
3. Rooms, guests workflow and operational policies configured.
4. WhatsApp business number connected when in scope.
5. Payment gateway configured: Asaas or Mercado Pago.
6. Fiscal capability configured when required.
7. Room-to-lock mappings verified.
8. Mobile/Desktop sessions validated.
9. Support contact and incident path recorded.
10. First reservation processed under controlled observation.

## Exit criteria
No open P0/P1 onboarding blocker, tenant isolation verified, payment path tested, and rollback/support contacts recorded.
