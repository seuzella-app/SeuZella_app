# Pagamentos — Escopo oficial

O Seu Zélla opera no Brasil com **Asaas** e **Mercado Pago**. Esses são os únicos gateways de produção no escopo atual.

`mock` permanece disponível somente para desenvolvimento/testes.

Qualquer referência a Stripe em commits, documentos históricos ou skills genéricas deve ser tratada como legado/fora de escopo e não pode reintroduzir dependências no runtime, readiness, billing, webhooks ou critérios de aceite.
