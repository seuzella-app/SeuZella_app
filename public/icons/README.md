# Seu Zélla — ícones do aplicativo

Os ícones finais do PWA serão fornecidos pelo proprietário da marca.

Não substituir estes arquivos por logos existentes ou assets genéricos.

Arquivos esperados quando os masters forem disponibilizados:

- `icon-192.png` — 192×192, `purpose: any`
- `icon-512.png` — 512×512, `purpose: any`
- `icon-192-maskable.png` — 192×192, `purpose: maskable`
- `icon-512-maskable.png` — 512×512, `purpose: maskable`

A arte maskable deve preservar o símbolo “Zé” dentro da safe zone central.
